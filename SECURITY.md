# Security policy

## Supported versions

The latest v2 release receives security fixes. Pre-v2 tags are unsupported.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's security advisory flow:

https://github.com/CHE3MZ/terminull/security/advisories/new

Do not open a public issue for a suspected vulnerability. Include the affected version, a minimal reproducer, and the impact you observed. We aim to acknowledge reports within three business days and will coordinate disclosure after a fix ships.

## Scope

In scope: terminal escape handling, ANSI parsing, pager and prompt subprocess use, generated project templates, and release artifacts. Out of scope: vulnerabilities in third-party terminals, shells, or operating systems; issues that require a compromised local account.
